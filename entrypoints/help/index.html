Welcome to Telegram Keyword Alert

Get notified when specific keywords or users appear in Telegram Web

Getting Started

1

Open Telegram Web

Go to web.telegram.org and log in.

2

Enable Notifications

Allow browser notifications to receive alerts.

3

Add Rules

Click the extension icon and create rules for keywords or users.

Features

Keyword Groups

Create groups with different colors and sounds for organizing your keywords.

Watch Users

Get notified when specific users send any message.

Filter Chats

Choose which chats to monitor, or watch all chats.

Snooze

Temporarily pause all notifications when you need focus time.

Data Management

Export your settings to back them up, import from a backup, or reset to defaults.
